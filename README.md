🇸🇦 نظرة عامة
مرشد التخصص تطبيق ويب مجاني يساعد طالب الثانوية في السعودية على معرفة التخصصات والجامعات التي تناسب نسبته الموزونة.
الطالب يدخل ثلاث درجات (المعدل التراكمي، القدرات، التحصيلي) واختياريًا IELTS أو STEP، فيحسب التطبيق نسبته بأوزان كل جامعة ويعرض له الفرص مصنفة بالألوان.
المشكلة
• كل جامعة تحسب النسبة بأوزان مختلفة (مثل 30/30/40 أو 20/30/50).
• حدود القبول تتغير كل سنة ومتفرقة بين مواقع الجامعات.
• شروط اللغة تحسم القبول في تخصصات مثل الطب والهندسة والحاسب.
• الطالب لا يعرف أي اختبار يستحق جهده في التحسين.
الحل
الحالة المعنى
🟢 مقبول نسبتك أعلى من الحد الأدنى
🟡 قريب تنقصك 5 نقاط أو أقل
🔴 بعيد الفارق كبير، مع اقتراح بدائل
🟣 تنقصك اللغة درجتك تكفي لكن شرط IELTS/STEP غير متحقق
✨ المميزات
• حساب النسبة الموزونة لكل جامعة بأوزانها الخاصة.
• ترشيح التخصصات وتصنيفها بالألوان مع شريط يوضح قربك من الحد الأدنى.
• كم أحتاج؟ يحسب الدرجة المطلوبة في التحصيلي أو القدرات لتخصص معين.
• التحقق من شرط اللغة (IELTS أو STEP).
• فلترة حسب الجامعة والمجال والحالة.
• صفحة التخصصات: تصفح كل التخصصات مع بحث وفلاتر، وبطاقة تفاصيل لكل تخصص (نبذة، مدة الدراسة، المجالات الوظيفية، والمتطلبات: الحد الأدنى والأوزان وشرط IELTS/STEP).

⚠️ تنبيه مهم
الحدود والأوزان في المشروع تقديرية للتوضيح وليست أرقام القبول الرسمية. راجع موقع الجامعة قبل أي قرار. نرحب بالمساهمة بالبيانات الرسمية.
